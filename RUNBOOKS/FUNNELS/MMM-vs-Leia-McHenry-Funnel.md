# Funnel Patterns — Music Marketing Manifesto vs Leia McHenry (Fans-first)

See also: [`FUNNEL_FRAMEWORKS_SYNTHESIS.md`](./FUNNEL_FRAMEWORKS_SYNTHESIS.md) (MVF pattern + lead magnet selection).

Purpose: reduce funnel setup friction by choosing a proven pattern and modernizing it for Nukage (short-form + performance template).

## Shared goal
Convert attention into an owned audience (email), then nurture into:
- repeat listeners
- show attendance
- purchases (music files now; merch later)

## Pattern A: “Music Marketing Manifesto” style (classic)
**What it usually looks like**
- Content (often blog/video) → opt-in → thank-you page → email follow-up → offer

**Strengths**
- Proven direct-response logic
- Clear CTA discipline
- Easy to measure

**Weaknesses (for 2026 Nukage)**
- Often assumes **blog posts** as the primary content engine
- Can feel heavy/slow if you’re shipping clips and sets

**Modernization for Nukage**
- Replace “blog post” with **short-form performance clip** as the main content unit.
- Replace “download the PDF” with **listen to the full track** (SoundCloud private link).
- Replace “read more” with **one CTA**: get the private link + bonus original.

## Pattern B: “Leia McHenry” method (similar goal, different mechanics)
**What it tends to emphasize**
- Lightweight capture + relationship-driven nurturing
- Often simpler to implement than full content→blog→opt-in stacks

**Why it may be easier**
- Fewer moving parts
- Less dependence on longform content

**How it maps to Nukage**
- Use the performance template sprint as the “relationship content stream”
- Weekly: one private drop (or cover) + a simple prompt (“reply with 1 word”) to increase engagement

## Minimum Viable Funnel (MVF) — recommended
This is the smallest thing that satisfies both patterns without blog dependency.

### Assets
- 1 landing page (per track campaign)
- 1 thank-you page (per track campaign)
- FluentCRM form + tag + automation
- SoundCloud private listening link
- Bonus original (download or stream link)

### Emails
- Email 0 (instant): deliver link + bonus + 1 micro-CTA (reply with 1 word)
- Email 1 (+1 day): “behind the build” + follow links
- Email 2 (+3 days): best 2–3 links (Spotify/YouTube) + “start here”
- Email 3 (+7 days): next drop / set debut invite

### Content input
- 3 shorts/week (Buffer cadence)
- Same CTA in each: “listen to full track”

## Decision: what to adopt
- Adopt MMM’s **measurement + CTA discipline**
- Adopt Leia’s **lightweight relationship cadence**
- Drop the blog dependency
