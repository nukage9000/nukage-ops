# Clip Inbox Metadata (for Buffer scheduling)

Purpose: add context per clip so Martin can write better captions + schedule correctly.

## How to use
1) Drop clip files into the Unraid share:
   - `/mnt/ai-pc/incoming/`
2) Add an entry below keyed by the **exact filename**.
3) Optional: include a preferred posting date, platform tweaks, or any "do not post" notes.
4) Commit + push this file in `nukage-ops` when you update it.

## Defaults (unless overridden per-clip)
- Schedule-only (never post-now)
- 3 shorts/week
- Platforms: IG + TikTok + YouTube
- Slots: Mon/Wed/Fri @ 12:15pm ET
