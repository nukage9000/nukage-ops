# Setup Sprint (Unlock) — Starting Point

Purpose: clear the high-leverage setup blockers so the rest of 2026 is mostly **production + growth**, not infrastructure.

## Outcomes (definition of done)
By end of this sprint, you can:
- run organic + ads without funnel anxiety (FluentCRM works end-to-end)
- generate consistent headshots/brand images on demand
- have a pipeline of song candidates (originals/VIPs/flips/covers) that feed the performance template + release machine

---

## Track A — Funnel backend (highest priority)
**Goal:** finish the funnel that’s already in progress.

### Deliverables
- Landing page template (TunePipe-style) confirmed + cloneable
- Thank-you page template confirmed + cloneable
- FluentCRM:
  - form works
  - campaign tagging works (per track)
  - Email 0 delivery works
  - nurture sequence active (+1d, +3d, +7d)
- SoundCloud private link delivery working (thanks page + Email 0)
- Bonus original offer wired (download/stream link)

**Guardrail:** do not run paid ads on bootlegs as the hero creative.

---

## Track B — Headshot LoRA (identity assets)
**Goal:** train LoRA(s) so you can generate realistic headshots and consistent brand visuals.

### Deliverables
- dataset collected + cleaned
- LoRA trained on GTX 4070
- 25–50 usable headshots + a few on-brand variants
- export set sized for: profile, thumbnails, stories, slideshow cards

---

## Track C — Inventory / candidates (9+ songs system)
**Goal:** build a portfolio of candidates so selection pressure can pick winners.

### Candidate pools
- **9-song stacks:** 3 flips + 3 VIPs (owned) + 3 Spotify originals (legacy/new)

### Extra surface area (optional but high upside)
- **3–5 trending songs to attempt to flip** (listen-only delivery)
- **3–5 covers to attempt to record** (vocal covers as a safer ‘recognizable hook’ lane)

### Minimum viable definition (for a candidate)
- has a 15–30s hero moment (“drop moment”) suitable for a clip
- is performable in the template (even if not fully finished)

---

## How this pays off
After this sprint, the weekly life becomes:
- build/perform + capture clips (3/week)
- always-on $3–$5/day lead gen to owned offers
- periodic Spotify bursts on winners
- weekly outreach + trend intel
