# Trend Bot (v1) — Spec

## Purpose
Surface a small number of **high-confidence remix/flip opportunities** that fit Nukage’s lane:
- **hard trap** (Juelz / heavier Hex Cougar side)
- with **Skrillex-ish drums**

Primary audience focus: **fans/listeners** (music files + performance clips), not producer products.

## Cadence
Weekly run (Friday morning) to feed the Friday noon outreach/strategy check-in.

## Output format (each candidate)
For each trend candidate, produce:
- Source link(s): YouTube Shorts / Spotify / Beatport / SoundCloud / etc.
- Why it’s trending (evidence + pattern)
- Nukage fit (sound + energy + identity)
- Flip angle (drop concept / arrangement idea)
- Content plan: 3–5 clip variants (visuals / DAW / finger drumming / performance template / IRL text overlay)
- Delivery recommendation:
  - **Bootleg/trend flip** → private listening link (no downloads)
  - **Original/VIP** → downloads OK
- Deadline: 24–72h window if applicable

## Constraints / reality
- TikTok/IG often require login; if scraping is blocked, request 3–5 seed links from Tom.
- Prefer sources accessible without auth.

## Where results live
- Append-only log: `nukage-ops/PLANS/TRENDS/TRENDS_LOG.md`

## Reporting routing
- Short blurb to Alerts (topic 32)
- Full list in Music Marketing topic (topic 2)
