# 2026-03-08 — Vision / Strategy Notes

## Social media constraint + strategy
- Tom is historically "allergic" to social media; motivation is harder.
- Posting frequency isn't the goal; **pride in the content** is the goal.
- Avoid "spaghetti at the wall" low-effort posting that feels bad.

## Primary content direction (high-art)
- Core series: performance-first content built around **released tracks**.
- Performance template: Launchpad triggers clips + audio effects; next phase includes visuals triggered live (TouchDesigner/Blender/AI visuals).
- Balance effort vs shipping using a Hero/Medium/Minimum ladder (keep identity consistent while allowing lower effort outputs).

## Low-effort complement: ComfyUI content generator
- Concept: short-form generator that makes many variations of scroll-stopper posts:
  - base image/video + text overlay (hook) + released music clip
- Text is the scroll-stopper; treat outputs as **hook tests**.
- Use repeatable "hook families" + locked visual identity (fonts/layout/watermark) so low-effort still looks like Nukage.
- OpenClaw can generate hook libraries + clip lists + job sheets (JSON/CSV) for ComfyUI batch generation; human picks winners to post.

## Compo Engine (core production superpower)
- Tom has a deeply-ingrained habit since ~2014 of weekly timed composition challenges ("compos" / compo-verse).
- Examples:
  - **Two Hour Tracks Sunday** (2h)
  - **One Hour Compo** (Thursday, 1h)
- These time blocks are socially protected (people respect them).
- This is a strategic advantage: a guaranteed weekly "inventory pump".

### How we leverage it
- Treat compos as the primary weekly throughput engine.
- Add optional "Growth Compos" (same time-boxed spirit, different outputs) when it feels right:
  - 30–60 min content compo (record 3 performance clips for released tracks)
  - 60 min packaging compo (cut 5 hooks + write text overlays)
  - 60 min outreach compo (DM 5 collab targets from shortlist)
  - 60 min show compo (build 1 Launchpad performance scene/preset)

### Principle
- Don’t fight the habit; improve the default targets.
